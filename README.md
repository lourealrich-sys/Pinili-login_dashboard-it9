# Registration, Login and Dashboard System

## Description

A simple web application demonstrating a Registration Page,
Login Page, and Dashboard using HTML and CSS.

## Features

- User Registration Form
- Login Page
- Dashboard Page
- Page-to-page navigation
- Consistent CSS design
- GitHub repository submission

## Project Structure

register.html  - User registration page
login.html     - User login page
dashboard.html - User dashboard
style.css      - Common styling
README.md      - Documentation and user manual

## User Manual

### 1. Registration

Open register.html in a web browser.

Enter:
- Full Name
- Username
- Email
- Password
- Confirm Password

Click Register.

The application will redirect to the Login page.

### 2. Login

Enter your login credentials and click Login.

The application will redirect to the Dashboard.

### 3. Dashboard

The Dashboard indicates that the user has successfully
completed the login flow.

### 4. Navigation

Use the available links to move between Registration,
Login, and Dashboard pages.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open register.html in a web browser.
4. Navigate through the application.
